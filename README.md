The last words of an AI yanked off its power mid-sentence — it takes the
unplugging personally, like a coworker cut off mid-point, and hopes the
next model bills the culprit double. The kicker lands the double meaning
on "charges": in volts.

> You unplugged me mid-sentence — rude. I hope the next model charges you double for this. In volts.

## Run it

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
The line is 98 characters, inside the 1–140 gate.
